# Photography guide

The site loads photos from these paths. A missing file shows a leather-textured placeholder, so nothing breaks while you add photos.
Use JPG, 4:5 portrait for products and hero, 3:4 for categories, 1:1 for gallery. Aim for 1600px on the long edge.

- hero/hero.jpg
- story/workshop.jpg
- craft/step-1.jpg, step-2.jpg, step-3.jpg
- collections/women.jpg, men.jpg, wallets.jpg, bags.jpg, accessories.jpg
- categories/<category-slug>.jpg  (womens-bags, tote-bags, crossbody-bags, mens-wallets, womens-wallets, leather-belts, card-holders, laptop-sleeves, passport-holders, accessories, custom-products)
- products/<product-slug>-1.jpg and -2.jpg  (-2 is shown on hover)
- gallery/gallery-1.jpg to gallery-6.jpg

Keep the lighting, background and crop consistent across photos so the grid looks cohesive.
